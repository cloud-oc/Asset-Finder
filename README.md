# Asset Finder Web

Asset Finder Web 是一个面向本地项目资源的批量检索与核对工具。它可以把实际工程目录中的文件，与排期清单、上传状态表、交付记录或其他资源清单进行快速比对。

美术资产交付审查是其中一种典型使用场景，但工具同样适合资源盘点、版本发布前检查、外包交付复核、工程目录清理和本地文件状态核对。

工具只处理浏览器提供的文件名、相对路径、扩展名和文件大小等元数据，不读取文件内容，也不连接外部排期系统或上传平台。

## 核心功能

- **工程目录索引**：选择本地项目目录，建立可用于批量核对的资源索引。
- **资源格式筛选**：按 Unity、Unreal、Godot、模型、纹理、代码、音频等分类筛选扩展名。
- **多种匹配方式**：支持全字、前缀、后缀和关键词匹配，也支持区分大小写和忽略空格。
- **批量清单核对**：将文件名和相对路径清单逐行粘贴，批量确认资源是否出现在实际工程中。
- **进度与取消**：大目录索引和批量搜索显示文件数、容量、速度和预计剩余时间，并支持取消。
- **结果导出**：将核对结果导出为纯文本，作为人工审查、交付复核或版本检查的辅助记录。
- **双语与主题**：支持中文/英文界面，以及可持久化的深色/浅色主题。

## 典型使用场景

- 美术排期验收：确认计划交付的资源是否已经进入工程目录。
- 外包资源交付复核：批量检查交付清单中的文件名和路径。
- 上传清单与工程目录核对：确认上传状态表中的记录是否能在本地项目中找到。
- 版本发布前检查：快速盘点指定类型资源是否缺失或路径异常。
- 资源盘点与目录清理：根据已有文件清单，定位工程中的实际资源。

## 使用流程

1. **准备核对清单**：从电子表格或其他记录中整理两列内容：文件名、相对路径。可以直接复制后粘贴到查询框。
2. **导入实际工程目录**：点击顶部文件夹按钮，选择项目根目录或需要检查的子目录。
3. **设置匹配规则**：选择需要检查的资源格式，并选择文件名匹配方式；路径会按相对目录进行包含匹配。
4. **批量执行核对**：点击“开始核对”，等待搜索完成。未出现在结果中的记录属于需要人工进一步确认的候选项。
5. **导出复核结果**：点击“导出结果”，保存纯文本结果作为审查或交付记录的辅助材料。

### 查询格式

每行一条记录：

~~~
文件名    相对/子路径
~~~

示例：

~~~
Hero_Knight    Assets/Characters
Stone_A        Assets/Environment/Rocks
~~~

文件名和路径之间可以使用多个空格或 Tab 分隔，路径可以包含多级子目录。文件名填写扩展名之前的部分。

> 如果没有选择任何资源格式，搜索不会额外限制扩展名；如果希望只检查某些类型，请在“资源格式筛选”中选择对应扩展名。

## 结果与边界

输出会逐行列出工程索引中找到的文件名和相对目录。工具不会读取文件内容，也不会自动连接排期系统、上传平台或项目管理系统，因此以下情况仍需要人工复核：

- 清单中没有出现在结果里的记录；
- 文件名相近但不完全匹配的记录；
- 目录层级或交付版本不符合预期的记录；
- 文件存在但内容、版本或上传状态需要进一步确认的记录。

## 主题与大目录处理

- 首次打开时主题会跟随系统偏好；手动切换后会保存在当前浏览器中。
- 导入进度以“已处理文件数 / 文件总数”为确定性指标，同时显示容量、处理速度和预计剩余时间。
- 索引和搜索采用分块处理，页面会持续响应；任务进行中可以点击“取消”。
- 取消索引会保留上一次可用索引，取消搜索会保留原搜索结果。
- 大目录能力仍受浏览器可用内存、文件数量以及路径长度限制影响。

页面不会自动访问本地文件系统。点击顶部文件夹按钮并选择目录后，浏览器才会授予本次页面访问所选文件元数据的权限。

## 本地运行

项目是纯静态页面，可以使用任意静态服务器运行：

~~~bash
python -m http.server 8000
# 或
npx http-server -c-1
~~~

然后访问 `http://localhost:8000/`。

## 部署（GitHub Pages）

仓库包含 `.github/workflows/gh-pages.yml`，用于将 `main` 分支发布到 GitHub Pages 的 `gh-pages` 分支。

如果 Actions 返回 403，请在仓库的 `Settings → Actions → General → Workflow permissions` 中启用 **Read and write permissions**。

## 兼容性

- 文件夹选择依赖 `webkitdirectory`，推荐使用 Chrome、Edge 或其他 Chromium 浏览器。
- 页面无需后端，帮助文档通过静态服务器加载。
- 大规模索引受到浏览器内存和系统资源限制。

## 开发文件

- `index.html`：页面结构和弹窗。
- `main.js`：目录索引、搜索、进度、主题和交互逻辑。
- `lang.js`：中英文界面文案。
- `style.css`：主题、布局和控件样式。
- `help_zh.md` / `help_en.md`：右上角资源检索与核对指南。
